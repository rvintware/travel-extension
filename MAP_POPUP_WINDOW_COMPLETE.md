# Map Popup Window Implementation - COMPLETE ✅

## Summary

Successfully converted the map view from an in-popup component to a standalone popup window, bypassing Chrome extension CSP restrictions while maintaining a compact, integrated UX.

## What Was Implemented

### 1. Created Tab Page (`tabs/map.tsx`)
- **New standalone page** for map rendering
- URL parameter parsing to get `tripId`
- Trip data fetching via existing API
- Loading and error states
- Close button to dismiss window

### 2. Updated TripMapView Component
- Made `onBack` prop **optional**
- Added conditional rendering for back/close button
  - Extension popup context: Shows "← Back" button
  - Popup window context: Shows "✕ Close" button that calls `window.close()`
- Component now works in both contexts

### 3. Updated TripDetail Button Handler
- Removed `showMapView` state (no longer needed)
- Removed conditional render of TripMapView
- Added `openMapPopup()` function using `chrome.windows.create()`
- Button now opens popup window instead of inline view

### 4. Window Configuration
- **Size**: 600px × 700px (optimal for map viewing)
- **Position**: Centered on screen
- **Type**: `'popup'` (no tabs/bookmarks bar - clean UI)
- **Focused**: true (brings to front)

## How It Works

### User Flow
```
1. User opens Trip Detail
2. Clicks "🗺️ Map View" button
3. Popup window opens (600×700px, centered)
4. map.html loads with ?tripId=xxx
5. tabs/map.tsx fetches trip data
6. TripMapView renders with Google Maps
7. No CSP restrictions! Maps loads successfully
8. User clicks "✕ Close" to dismiss window
```

### Technical Flow
```
TripDetail.tsx
    ↓
openMapPopup()
    ↓
chrome.windows.create({
  url: 'map.html?tripId=xxx',
  type: 'popup',
  width: 600,
  height: 700
})
    ↓
tabs/map.tsx loads
    ↓
Parse URL params
    ↓
Fetch trip via GET /api/trips/:id
    ↓
Render <TripMapView trip={trip} />
    ↓
Google Maps loads (no CSP issues!)
    ↓
Markers render with numbers
    ↓
Info windows work on click
```

## Why This Fixes the CSP Problem

### Extension Popup (Before - Blocked)
```
Extension Popup (popup.html)
    ↓
CSP: script-src 'self'
    ↓
Blocks: https://maps.googleapis.com
    ↓
❌ Google Maps cannot load
```

### Popup Window (After - Works!)
```
Popup Window (map.html)
    ↓
CSP: More relaxed for extension pages
    ↓
Allows: External scripts
    ↓
✅ Google Maps loads successfully
```

## Window Size Rationale

**600px × 700px chosen because:**
- Larger than extension popup (400×600) for better map viewing
- Not too large (stays compact, doesn't dominate screen)
- Good aspect ratio for maps (slightly taller)
- Fits on most laptop screens with room to spare
- Professional UX (similar to Google Calendar popup)

**Alternative sizes available:**
```typescript
// Compact (matches extension)
{ width: 400, height: 600 }

// Standard (current)
{ width: 600, height: 700 }

// Large (more map space)
{ width: 800, height: 900 }
```

## Troubleshooting

### If window doesn't open:
- Check: `chrome.windows` permission (already granted)
- Check: `map.html` exists in build folder
- Check: DevTools for errors in background script

### If map doesn't load in window:
- Check: `.env.local` has `PLASMO_PUBLIC_GOOGLE_PLACES_API_KEY`
- Check: DevTools console for API errors
- Check: Network tab for failed requests

### If markers don't appear:
- Check: Trip has locations with valid lat/lng
- Check: `/api/trips/:id/map-data` returns data
- Check: Console for "[TripMapView] Map data loaded"
